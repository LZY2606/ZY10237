# 迁徙轨迹审理台

面向野外遥测项目的本地审理服务：导入 GPS 定位、加速度摘要、设备开关机事件与电池状态，
在本地坐标网格上评估定位质量、识别移动/停留片段，并保留受缺测影响的多个分段候选。
同一动物更换项圈后开始新的设备代次。

## 运行

```bash
# 安装（编译打包）
mvn -q -DskipTests package

# 演示（先跑自动化验收测试，再启动服务）
mvn -q test && mvn -q spring-boot:run -Dspring-boot.run.arguments=--server.port=5577
# 打开 http://127.0.0.1:5577 应看到“迁徙轨迹审理台”
```

数据库为当前目录下的 SQLite 文件 `migration.db`，首次启动自动建表并导入固定 fixture。

## 数据口径

- **坐标系**：轨迹使用本地坐标网格 `LOCAL_GRID`（单位：米），页面仅用 SVG 网格展示，不下载地图。
- **时间**：所有时间戳为 epoch 秒；相邻定位按到达顺序（导入序）遍历。
- **速度**：仅在同时满足以下条件的相邻定位间计算：同一设备代次、两端均未拒绝、
  时间正向（`dt > 0`）、间隔不超过参数版本的 `gap_threshold_sec`。
  阻断原因：`CROSS_GENERATION`（跨代次）、`LOW_QUALITY`（端点被拒绝）、
  `CLOCK_ROLLBACK`（时间倒退）、`LONG_GAP`（长缺测空档）。
- **时钟回跳 vs 空间回返**：同一代次内设备时间戳倒退判定为 `CLOCK_ROLLBACK`（设备异常）；
  时间单调但位置回到更早定位 150 m 内判定为空间回返（动物行为），两者分开统计、互不误判。
- **长缺测空档**：间隔超过阈值的相邻对不连线，页面不以直线伪造迁徙路径，仅以 ⚠ 标记空档。
- **时长上下界**：片段时长下界 = 片段内首末定位的实测跨度；上界 = 扩展到相邻观测点的跨度，
  用于表达缺测窗口的不确定度，二者分别统计。
- **误差椭圆 CRS 守卫**：任一定位的误差椭圆坐标系与轨迹坐标系（`LOCAL_GRID`）不一致时，
  `/api/distance` 拒绝距离判定并返回 409。
- **行为分段**：按参数版本（`default` 0.5 m/s、`sensitive` 0.2 m/s）的速度阈值把定位分为
  MOVE/STAY 并合并为片段；两个参数版本各生成一个状态序列候选，可同时保留。
- **可追溯**：每个片段记录原始定位区间（`start_fix_id`–`end_fix_id`）、时间窗、代次与参数版本。

## 固定 fixture

定位序列横跨项圈更换（`COLLAR-A` → `COLLAR-B`），包含：

- 代次 1：正常移动 → 停留 → 一个低质量点（HDOP 9.8，可拒绝）→ 动物返回旧位置（#7 回到 #2 附近）
  → 设备时钟回跳（#8 时间戳倒退）→ 长时段无定位（#8→#9 约 2 小时）→ 继续移动；
- 定位 #11 的误差椭圆坐标系为 `WGS84_GEO`，用于验证 CRS 不符时拒绝距离判定；
- 代次 2（新项圈）三个定位；旧设备在更换后补传一条迟到记录（#15，仍属代次 1），
  验收保证跨代次不计算速度。

## 审理操作与重放

页面支持：拒绝低质量定位、确认设备更换边界、调整行为分段状态、保留两个状态序列候选、
切换当前显示的候选。所有审理动作写入 `review_action` 表留痕。

- **导出运行记录**：`GET /api/export`（页面“导出运行记录 JSON”），含审理动作、候选与片段快照。
- **清空重放**：页面“清空数据库并重新导入复核”按钮或 `POST /api/reset`，
  清空全部表并重新导入固定 fixture，可反复复核；也可删除 `migration.db` 后重启服务达到同样效果。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 页面全量状态（定位、速度、折线、候选、片段、异常、加速度、事件、电池） |
| POST | `/api/fixes/{id}/reject` | 拒绝低质量定位 |
| POST | `/api/generations/{id}/confirm` | 确认设备更换边界 |
| POST | `/api/segments/{id}/adjust` | 调整片段状态（MOVE/STAY） |
| POST | `/api/candidates/{id}/retain` | 保留状态序列候选 |
| POST | `/api/candidates/{id}/activate` | 切换当前显示的候选 |
| GET | `/api/distance?a=&b=` | 距离判定（CRS 不符返回 409） |
| GET | `/api/export` | 导出运行记录 JSON |
| POST | `/api/reset` | 清空数据库并重新导入 fixture |

## 自动化验收

`src/test/java/com/example/migration/AcceptanceTests.java` 覆盖：
跨代次（含迟到记录）不计算速度、长空档不画直线路径、CRS 不符拒绝距离判定（服务层 + HTTP 409）、
时钟回跳与空间回返区分、时长上下界有序、拒绝定位阻断速度、双候选可保留、导出与清空重放。
